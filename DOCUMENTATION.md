## Automated Generation Steps

This project utilizes several automated generation steps to maintain documentation, tool models, and integration metadata.

### Standard Cell Documentation Generation
The standard cell documentation is automatically generated by parsing the Verilog netlist to extract cell descriptions and pin lists.

- **Script:** `scripts/generate_cell_docs.py`
- **Input:** `ihp-sg13g2/libs.ref/sg13g2_stdcell/verilog/sg13g2_stdcell.v`
- **Output:** ReST files in `docs/libraries/sg13g2_stdcell/cells/` and layout images in `docs/_static/images/`.
- **Process:**
  1. The script parses the Verilog netlist to find module definitions.
  2. It extracts descriptions from special comments (e.g., `cell_description:`).
  3. It identifies input and output pins.
  4. It generates individual ReST files for each cell.
  5. It copies rendered GDSII images from `rendered_cells/` to the Sphinx static directory.
- **Build Command:**
  ```bash
  python3 scripts/generate_cell_docs.py
  sphinx-build -b html docs/ docs/_build
  ```

### KiCAD Model Generation
KiCAD schematic models for the standard cells are automatically generated from their SPICE subcircuits.

- **Script:** `ihp-sg13g2/libs.tech/kicad/scripts/spice_to_kicad.py`
- **CI Workflow:** `.github/workflows/kicad_models.yml`
- **Input:** `ihp-sg13g2/libs.ref/sg13g2_stdcell/spice/sg13g2_stdcell.spice`
- **Output:** KiCAD schematic files (`.kicad_sch`) in `output_kicad/`.
- **Dependencies:** Requires the [nl2sch](https://github.com/tpecar/nl2sch.git) tool.
- **Process:**
  1. Parses SPICE `.subckt` definitions.
  2. Converts the internal connectivity to a Protel netlist format.
  3. Invokes `nl2sch.py` using templates from `ihp-sg13g2/libs.tech/kicad/templates` to generate the schematic.

### OpenROAD Export Generation
To support the OpenROAD-flow-scripts, an export metadata file is generated to track PDK file changes.

- **Script:** `ihp-sg13g2/libs.tech/openroad/generate.py`
- **Input:** Various PDK files (GDS, LEF, LIB, Verilog) within `ihp-sg13g2/libs.ref/`.
- **Output:** `ihp-sg13g2/libs.tech/openroad/export.yml`
- **Process:**
  1. Scans defined lists of IO, SRAM, and Standard Cell files.
  2. Calculates MD5 checksums for each file.
  3. Generates a YAML file containing file paths, checksums, and their intended destinations in the OpenROAD environment.
